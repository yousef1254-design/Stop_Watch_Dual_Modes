# Stop_Watch_Dual_Modes

## 🔷 Key Features of the Project
* **Two Modes:** The system can work as a count-up stopwatch or a count-down timer.
* **Smart Time Setting:** Buttons to increase or decrease hours, minutes, and seconds (active only in Pause mode).
* **Alarm System:** In count-down mode, a buzzer automatically turns on when time reaches zero.
* **Quick Control:** Dedicated buttons to pause, resume, or reset.

## 🛠️ Technical Details & Tools
* **Microcontroller:** ATmega32
* **Display:** 6-digit 7-segment display using 7447 decoder
* **Software:** Eclipse IDE (C Language)
* **Simulation:** Proteus
