# Stop_Watch_Dual_Modes
🔹 Key Features of the Project:
Two Modes: The system can work as a count-up stopwatch or a count-down timer. 
Smart Time Setting: I added buttons to increase or decrease the hours, minutes, and seconds. To prevent mistakes, these buttons only work when the timer is in Pause mode. 
Alarm System: In the count-down mode, a buzzer automatically turns on when the time reaches zero. 
Quick Reset & Resume: Dedicated buttons to easily pause, resume, or reset the time.
🛠️ Technical Details & Tools:
Microcontroller: ATmega32. 
Display: 6-digit 7-segment display using a 7447 decoder. 
Software: The code was written in Eclipse using C language.
Simulation: The hardware circuit was designed and tested on Proteus.
